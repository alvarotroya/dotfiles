The blocker that was fixed

Node had to become real

node, npm and npx existed only as lazy zsh functions. Any process that isn't a zsh shell — an MCP server, a SessionStart hook, an agent CLI — calls execvp("npx") and gets ENOENT. That's why the Playwright MCP server was dead. Four of the five tools install through npm, so nothing could proceed until this was real.

# .zshenv — a symlink you control, first on PATH
export NVM_DIR="$HOME/.nvm"
[[ -d "$NVM_DIR/current/bin" ]] && path=("$NVM_DIR/current/bin" $path)

# changing node version = repoint the symlink, never edit PATH
nvm install v26.x.x && ln -sfn "$NVM_DIR/versions/node/v26.x.x" "$NVM_DIR/current"

The lazy node/npm/npx functions are gone; nvm() itself stays lazy, since sourcing nvm.sh is slow and is only needed to switch versions. typeset -U path now dedupes PATH, which had grown to roughly 20 entries with Android SDK paths repeated five times over.

How the pieces sit

The five

What each one is actually for

Pi

second harness

Read, write, edit, bash, and a system prompt of a few hundred tokens — the bet being that frontier models already know what a coding agent is. Its real value to you is as a control: when something works in Pi but not Claude Code, the harness is the variable.

pi                      # start in current project
pi -p "one-shot"        # non-interactive
pi -c                   # continue last session

# first run, inside the TUI:
/login   -> Claude Pro/Max
/login   -> ChatGPT Plus/Pro (Codex)
/model   -> pick one, Ctrl+S saves it as the startup default
Cost

Anthropic bills third-party harness usage from your extra usage balance, per token. It does not draw on Claude plan limits — Pi on your Claude subscription costs real money in a way Claude Code does not.

Herdr

multiplexer

tmux-shaped, but it recognizes coding agents inside panes and exposes their state over a socket API — so agents can spawn panes and wait until another agent is genuinely blocked, rather than you playing switchboard. A single 22 MB Rust binary.

herdr                     # launch / attach the persistent session
herdr status
herdr integration status  # claude, codex, pi — all current (v8)
herdr --skill             # the skill that lets an agent drive herdr

The installed integrations are state-reporting hooks: each agent reports idle / working / blocked, which is what makes the mission-control view worth having.

Lavish

review surface

Turns an HTML artifact into a local page you annotate — click elements, select text, queue prompts — and the feedback flows back to the agent through a long poll. Mermaid diagrams become editable Excalidraw whiteboards.

lavish-axi file.html            # open / resume a session
lavish-axi poll file.html       # agent waits here for your feedback
lavish-axi export file.html     # one portable HTML, assets inlined
lavish-axi stop                 # shut the background server down
Careful

lavish-axi share publishes to ht-ml.app, a third-party host, and is public by default. Pass --private for a password-gated page.

Firstmate

agent distro

Not a package — the cloned repo is the distro. Launching any supported harness inside it turns that agent into a "first mate" that spawns crewmates, each in its own git worktree and its own visible tmux window (or Herdr tab), supervises them, and hands back finished PRs. You talk to one agent; it juggles the tabs.

cd ~/repos/mine/firstmate
claude          # or: pi / codex

# then, in plain language:
# "look at project X, fix the flaky login test and add dark mode"

Modes are per project: no-mistakes, direct-PR, local-only. Update from inside with /updatefirstmate. gh is already authenticated as alvarotroya.

Rebuilding from scratch

Everything is pinned in your dotfiles repo. Stow the configs, run one script, do the two logins. The script is idempotent and takes individual phase names if you only want a piece of it.

git clone git@github.com:alvarotroya/dotfiles.git ~/repos/dotfiles
cd ~/repos/dotfiles && stow zsh -t ~/
./bootstrap/agents.sh

# or one phase at a time:
./bootstrap/agents.sh node npm skills lavish herdr firstmate
